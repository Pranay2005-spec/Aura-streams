# PrimeView 🎬

**PrimeView** is an online movie streaming website — one of my first full web projects built during college. This project showcases a complete dynamic web application using core web technologies, and it was a great hands-on way for me to learn back-end and front-end development. :contentReference[oaicite:0]{index=0}

---

## 🚀 Overview

PrimeView is a fully functional movie streaming platform where users can:

- Browse and search for movies
- View movie categories and details
- Play video content directly in the browser
- Sign up / log in to access personalized features

This app is built with web fundamentals like HTML, CSS, JavaScript, and PHP, connected to a **MySQL database** to store user and movie data. :contentReference[oaicite:1]{index=1}

---

## 🛠️ Technologies Used

| Layer | Technology |
|-------|------------|
| Front-end | HTML, CSS, JavaScript |
| Back-end | PHP |
| Database | MySQL |
| Server | Apache (XAMPP / LAMP) |

---

## 🧩 Features

- **Responsive UI** – Works smoothly on desktop and mobile.
- **User Authentication** – Sign-up and login system.
- **Movie Library** – Organized browsing of movie listings.
- **Search** – Find movies using search keywords.
- **Media Player** – Play movies directly on the site.
